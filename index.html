Einrichtung

Einmalig deine Supabase-Verbindung hinterlegen. Die Werte bleiben nur auf diesem Gerät gespeichert.

Im Supabase-Dashboard unter Project Settings → API Keys: die Project URL und den Publishable Key (beginnt mit „sb_publishable_") – bei älteren Projekten der anon-Key („eyJ…"). Dieser Schlüssel gehört in den Client; geschützt wird über RLS. Den geheimen secret/service_role-Key nicht verwenden.

Daten

Alte Tankliste als CSV importieren. Erkannte Spalten: datum, km_stand, liter, literpreis, total, waehrung, vollgetankt, ort (Semikolon oder Komma; Dezimalkomma erlaubt).

Backup lädt alle Tankungen als JSON-Datei herunter. Wiederherstellen liest eine solche Datei und fügt fehlende Einträge hinzu – exakte Doppel (gleicher km und Datum) werden übersprungen.
